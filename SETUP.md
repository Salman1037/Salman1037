# GitHub Profile Setup — Neon Cyber Final

1. Open `https://github.com/Salman1037/Salman1037`.
2. Upload or replace `README.md` and the `assets/` files from this package.
3. If `.github/workflows/snake.yml` is already installed, keep it; otherwise upload the included workflow.
4. In **Settings → Actions → General**, allow actions and give the workflow read/write permissions (if available).
5. In **Actions → Generate Contribution Snake**, click **Run workflow** on `main`.
6. Wait for the run to succeed, then refresh `https://github.com/Salman1037`.
7. Check that the `output` branch contains `github-snake.svg` and `github-snake-dark.svg`.

## Notes
- The broken third-party streak-statistics widget was intentionally removed.
- The SVG banner works without GitHub Actions; the snake uses GitHub Actions.
- The banner includes a static file as a reduced-motion fallback.
- Update project URLs only if you have confirmed the live pages and permission to share them.
- Do not upload private client source code, credentials, or private repository URLs.
- GitHub profile Markdown cannot support arbitrary JavaScript or CSS.
